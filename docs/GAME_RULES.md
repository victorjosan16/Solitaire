# Game rules

## Deal
* 52 unique cards. Shuffle: Mulberry32 PRNG + Fisher–Yates (`Deck.shuffled(seed)`), frozen by a
  regression test so a seed means the same deal forever.
* Dealing row by row: row *r* gives one card to every column *c ≥ r*; the card landing in column
  *r* is face up. Result: columns of 1…7 cards, only top cards face up; 24 cards in the stock.

## Moves
* **Tableau**: descending rank, alternating colour. Any face-up valid run may move. Only a King
  (or a King-headed run) may go to an empty column. Exposed face-down tops flip automatically.
* **Foundations**: one per suit (clubs, diamonds, hearts, spades), Ace → King, one card at a time.
  Dropping on any foundation slot routes to the card's own suit.
* **Foundation → tableau**: allowed by default (setting "Allow moves from foundations").
* **Stock**: Draw 1 or Draw 3. When the stock is empty, tapping it turns the waste over in the
  original order. Stock passes: unlimited (default) or, when "Unlimited stock passes" is off,
  2 recycles in Draw 1 and 3 in Draw 3.
* **Tap-to-move** priority: foundation (if "Tap sends cards to foundations first"), then the
  left-most non-empty tableau column, then an empty column (never a pointless King hop).

## Undo, restart, new game
* Unlimited undo of every move type (draw, recycle, transfers, auto-flips); undo also restores
  score and move count exactly. Undo count is recorded as an assist.
* Restart: same deal, same game id (results still recorded once).
* New game while a game with moves is in progress counts that game as a loss.

## Hints & "no moves"
Hint priority: tableau→foundation, waste→foundation, tableau runs that reveal a card or empty a
column, partial runs that expose a foundation card, waste→tableau, then the stock **only if** a
full stock cycle would surface a playable card. If none: "No useful moves" with Undo / Restart /
New game. The game is never declared lost automatically.

## Auto Finish
Offered only when every tableau card is face up and a greedy foundation-only plan (including
draws/recycles within the pass limit) provably reaches 52 foundation cards. Each step is a
validated move; Skip applies the rest instantly, Cancel stops with a consistent board.

## Shuffle (paid assist)
* Every card that is **not on a foundation** (tableau incl. face-down cards, stock, waste) is
  shuffled and dealt again in the opening shape: row by row into columns 1…7, only each column's
  top card face up; cards beyond 28 form the stock (waste empty). Foundations, score and the
  stock-pass counter are unchanged; counts as one move.
* Cost **50 coins**, or an opt-in rewarded ad (shuffle happens only on the earned-reward callback,
  once per reward event). Maximum **3 per game**. Confirmation is required.
* Cannot be undone; the undo history restarts from the shuffled position ("Restart deal" still
  returns to the original deal).
* Deterministic: seed = FNV-1a(`<deal seed>:<game id>:<shuffle #>`), so a future server can replay
  it for leaderboard validation. Shuffled wins are **assisted**: no +25 clean bonus, not "pure",
  and excluded from any main leaderboard.

## Winning
Win = all 52 cards on foundations (13 per suit).

## Deal types
* **Random**: arbitrary seed; may be unsolvable; never labelled winnable.
* **Winning**: from `verifiedDraw1Seeds` (400) / `verifiedDraw3Seeds` (200). Generated by
  `tool/generate_winning_seeds.dart`: the DFS solver (which knows face-down cards) must return a
  move list that replays to a win through `KlondikeEngine` with unlimited passes and foundation
  moves allowed. Seeds the solver could not finish within its budget are discarded (that says
  nothing about their solvability). CI re-verifies a sample.
  Limitation: winnability is guaranteed for the default rules; with limited passes or
  foundation moves disabled a "winning" deal may be harder or impossible.

## Scoring (version 1, "Classic Standard")
| Event | Points |
|---|---|
| Waste → tableau | +5 |
| Waste → foundation | +10 |
| Tableau → foundation | +10 |
| Revealing a tableau card | +5 |
| Foundation → tableau | −15 |
| Recycling the waste | −100 (Draw 1) / −20 (Draw 3) |
| Time bonus at victory (≥30 s) | 700 000 ÷ seconds |

Score never goes below 0 (the clamped delta is what undo reverses). Hints and undos do not change
points; they are recorded as assists. Leaderboard segmentation key: `GameConfig.rulesKey`
(draw mode, pass limit, foundation moves) + scoring version + assists.

**Combos** count consecutive productive moves (to a foundation or revealing a card); draws,
recycles and undo reset them. Cosmetic only.

## Daily challenge
* Identified by the device's **local calendar date** (`yyyy-MM-dd`). Each date maps to a verified
  Draw-1 winning seed (`dayIndex since 2025-01-01 mod 400`), standard rules, playable offline.
* Playable: today and every past day of the current and previous month; never future days.
* Reward 150 coins once per date (`daily:<date>`), only when completed on that date. Past days earn
  a check mark and stats. Changing the device clock can at most unlock a future day's challenge;
  it cannot repeat a reward. Competitive/cloud rewards would require server time (not implemented).

## Economy (virtual coins — no cash value, cannot be bought or withdrawn)
| Source | Coins |
|---|---|
| Win (Draw 1 / Draw 3) | 50 / 75 |
| Win with no hints, no undo, no shuffle | +25 |
| Speed bonus (active time): < 3 min / < 5 / < 7 / < 10 | +40 / +25 / +15 / +5 |
| Daily challenge (on its date) | 150 |
| Achievements | 50 – 1 000 each |
| Rewarded ad on victory (opt-in) | doubles that win's coins, once |

Speed bonus rules: games are designed to last up to 10 minutes of active play (pauses and
background time are not counted). The bonus is paid only on the **first attempt** of a deal (not
after "Restart deal") and **once per deal** (ledger key `speed:<draw>:<seed>`), so replaying a
known daily or winning deal cannot farm it.

Spending: cosmetics 300 – 1 000, hint pack 3 hints for 60, shuffle 50. New players start with 250 coins and
5 hints. Opt-in rewarded ad: +3 hints. XP: 100 + score/100 per win, 10 per loss; level *L*
requires 75·(L−1)·L XP.
